# Code of Conduct

NOTE: This file was generated by AI (GitHub Copilot) on 2025-11-14.

The TPNEBOT project aims to foster a welcoming, respectful, and collaborative environment. This Code of Conduct outlines expected behavior and processes for addressing issues.

## Our Standards
Examples of positive behavior:
- Using inclusive and respectful language.
- Being considerate of differing viewpoints and experiences.
- Gracefully accepting constructive feedback.
- Focusing on what is best for the community and project.

Unacceptable behavior includes:
- Harassment, discrimination, or derogatory comments.
- Publishing private information without permission.
- Sustained disruption of discussions.
- Any behavior that compromises security, privacy, or safety.

## Responsibilities
- Maintainers: review contributions fairly, enforce this Code, and act on reports.
- Contributors: follow guidelines, refrain from harmful actions, report issues.

## Reporting
If you observe or experience unacceptable behavior:
1. Document details (time, context, participants).
2. Email the maintainers or open a private issue if available.
3. For urgent security concerns, follow the Security Policy instructions.

## Enforcement
- First incident: reminder and clarification of expectations.
- Repeated or severe incidents: temporary or permanent exclusion from contribution channels.

## Scope
Applies to all project spaces: repository, issues, pull requests, discussions, and any community integrations (Discord server, forum, etc.).

## Attribution
Inspired by widely adopted open source community guidelines.

## Changes
Modifications may be proposed via pull request. Significant changes require community review.

## Contact
Use repository issue tracker or designated email published in the project README.

End of Code of Conduct.
