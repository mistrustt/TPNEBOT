# Database Schema

NOTE: This file was generated by AI (GitHub Copilot) on 2025-11-14.

Overview of key SQLAlchemy models defined in `database/models.py`.

## Design Principles
- Use explicit primary keys and indices for common query paths.
- Favor Numeric with precision for currency values (avoid float rounding errors).
- Keep moderation, economy, and gameplay concerns separated by table clusters.

## Moderation Cluster
- Punishment: Records moderation actions including type, reason, duration.
- CaseNote: Supplementary notes for existing punishment case.
- WatchdogLog / WatchdogSetting: Audit log of moderator commands and enable flag.
- JailSetting / JailedUser: Jail role mapping and active jailed users with original roles snapshot.
- ImageMuteSetting: Mapping for image mute role per guild.
- LockdownChannel: Tracks locked channels for emergency state.
- UserAlt: Relationship of main user to alternate accounts.

## Access Control
- CommandStatus: Command enable state globally or scoped by channel.
- CommandRoleRestriction: Role gate for commands (unique per guild and command).
- Blacklist: User level exclusion with reason.

## Economy Core
- Wallet: User currency wallet with keys, seeds, balance, nonce.
- BankAccount: Optional separate bank balance.
- Transaction: Movement of currency between users (references hashed block chain field if used).
- Item / ShopItem: Inventory items and global shop offerings (with effect, cooldown fields).
- Bounty: User posted rewards for target actions.
- Block: Ledger block including index, previous hash, transactions JSON.
- Supply: Aggregate supply counters (total, circulating, treasury).
- CryptoAsset / CryptoPrice: Basic portfolio and price tracking.

## Gameplay and Fairness
- GameStats: Wins, losses, total wagered per game.
- GameHistory: Detailed per play record including seeds, nonce, hash for verification.
- MinesSettings: Parameters for mines game (bomb count, gem count, multiplier).
- Streak: Activity streak tracking.
- Task: Generic tasks list (user oriented trackers).

## User Metadata
- UserRoleHistory: Snapshot of role arrays over time.
- UserNameHistory: Track username or nickname changes and type.
- Reputation: Simple integer reputation score.
- ReactionSettings: Toggle for self reaction allowance.
- LastFMusers / LastFMvotes: Music integration user profile and voting tallies.
- UserTimezone: Timezone string.
- UserLocation: Encrypted coarse location string (no exact latitude/longitude).
- FavoriteSongs: Stored song titles by user.
- BoosterRole: Tracks booster role assignment per guild user.
- Juul: Shared object mini game state (holder, stats).

## Music and Voice
- TempVoiceChannel: Dynamic temporary voice channels with owner references.
- JTCSettings: Join to create system setup record.

## Data Integrity Constraints
- Non negative balance constraints on Wallet and BankAccount.
- Unique constraints ensuring one wallet per user and uniqueness for combined keys (e.g., CommandRoleRestriction).
- Indices on GameHistory for user and hash queries accelerate fairness audits.

## Seed and Fairness Fields
Wallet includes server seed, previous server seed, client seed, nonce tracking. Rotation updates server seed and stores previous until verification window closes. Nonce increments per draw across games.

## Suggested Index Additions (Future)
- Add indices for frequently toggled command lookups on CommandStatus (command_name, channel_id).
- Add composite index for (guild_id, command_name) on CommandRoleRestriction.

## Migration Strategy
Currently tables initialize programmatically. For larger schema changes adopt Alembic and versioned migration scripts to enable rollback and audit.
